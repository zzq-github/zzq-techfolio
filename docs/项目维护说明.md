# 项目维护说明

本文说明现有实现的维护入口、交互约定、测试与部署条件。作品集介绍与在线预览见 [README](../README.md)。

## 内容与文案

个人信息、能力、项目、工作经历、开源作品、个人产品和教育经历统一维护在 [profile.ts](../src/data/profile.ts)，不要在文档中重复维护一份履历。

- 项目介绍应区分实际项目背景、个人职责与本站演示，不将团队成果全部归为个人贡献，不添加未经核实的指标或项目链接。
- `Project.contribution` 是可选字段，用于描述职责、关键问题与实现、交付内容和展示边界；未配置的项目使用原有核心工作介绍。
- GIS 数据急救箱属于个人商业产品，不归入开源作品。项目状态和外部链接以内容数据为准。
- 组件文案使用 `usePreferences().t()`，结构化展示内容使用 `useContent()`。中文变更应同步更新 [en.ts](../src/i18n/en.ts) 中以完整中文原文为键的译文。
- 场景定义在 [sceneData.ts](../src/components/scenes/sceneData.ts)，场景控件译文在同目录及 `modules/` 内的 `*Copy.ts`。
- [index.html](../index.html) 维护默认标题、描述、分享卡片及 canonical；语言切换时的元信息由 [PreferencesProvider.tsx](../src/preferences/PreferencesProvider.tsx) 同步。

站点不提供 PDF 简历下载。不将个人附件、客户数据、内部地址或密钥写入源码与静态资源；隐藏按钮或关闭展示开关不能代替移除敏感数据。

## 功能配置

配置入口为 [site.ts](../src/config/site.ts)。

| 字段               | 当前值  | 实际作用                                                   |
| ------------------ | ------- | ---------------------------------------------------------- |
| `enableThreeGlobe` | `true`  | 启用首页三维地球增强；关闭时保留静态后备，不控制项目实验室 |
| `enableEmail`      | `true`  | 显示联系区发送邮件与复制邮箱入口                           |
| `enablePhone`      | `false` | 预留字段，当前未接入手机号展示组件                         |
| `enableAnalytics`  | `false` | 预留字段，当前未接入访问统计服务                           |

## 语言、主题与状态

| 状态                                 | 保存范围       | 行为边界                                                 |
| ------------------------------------ | -------------- | -------------------------------------------------------- |
| 中文 / English                       | 本机浏览器存储 | 刷新恢复，同源标签页同步；存储不可用时仍可在当前页面切换 |
| 亮色 / 暗色 / 跟随系统               | 本机浏览器存储 | 手动选择优先；跟随系统时响应系统配色变化                 |
| 场景参数、模式、图层、选择与复核记录 | 当前页面会话   | 切换场景保留；刷新后恢复默认，不写入长期存储             |
| 自由镜头与帧级飞行位置               | 当前场景实例   | 切换场景不承诺恢复；桥梁根据已检查点续行                 |

[public/preferences.js](../public/preferences.js) 在 React 加载前应用主题，避免首屏闪烁。页面使用单一 URL 切换语言，没有独立英文路由。

三维会话由 [sceneSession.ts](../src/components/scenes/sceneSession.ts) 和 [SceneLab.tsx](../src/components/scenes/SceneLab.tsx) 管理。切换语言、主题、展开或收起不应重建当前画布。恢复默认参数只作用于当前场景；重置视角不应改动业务参数。

## 三维演示与交互

首页地球入口为 [GeoGlobe.tsx](../src/components/hero/GeoGlobe.tsx)，渲染实现为 [globeEngine.ts](../src/components/hero/globeEngine.ts)。项目实验室的共享渲染在 [sceneEngine.ts](../src/components/scenes/sceneEngine.ts)，各场景模型与计算在 [modules/](../src/components/scenes/modules)。

| 场景     | 主要交互                                   | 模拟边界                                                                                            |
| -------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| 土石方   | 设计标高、挖填分区、原始地形叠加、施工进度 | 以 2.5 m 栅格积分示意挖填量，场景 1 单位为 10 m；分析模式展示设计完成面，不把设计方量当作已施工方量 |
| 桥梁巡检 | 自动巡检、单步检查、病害定位、筛选、复核   | 预设路线和病害，按距离、朝向及遮挡判断发现，不运行 AI 图像识别                                      |
| 海上风电 | 风速参数、风机与海缆布局、旋转观察         | 合成风场和动画示意，不接入实时风速或发电监测                                                        |
| 水利淹没 | 水位调节、坝体阻隔、建筑受淹、分级水深     | 静态地形上的四邻域水源连通分析，不计算流速、降雨过程或洪峰到达时间                                  |
| 园区     | 建筑属性、楼层剖切、图层切换、日照时刻     | 程序化概念模型，不接入倾斜摄影资产或 SuperMap 服务                                                  |

手机展开体验时，竖屏模型区与可滚动控制区分开，横屏改为左右分区；控制面板可收起。触屏拖动需要显式开启，默认保留页面滚动，不劫持滚轮。应保留播放、暂停、旋转、缩放、重置视角和关闭展开视图的可达入口。

地球与实验室按需加载，离屏或页面进入后台时暂停绘制；实验室同一时间只保留一个项目 WebGL 画布。切换场景须释放几何、材质、事件监听和图形上下文，避免累积资源。绘制上限为 30 FPS，实验室 DPR 上限为 1.5；减少动态效果时默认暂停动画。

不支持 WebGL 或图形上下文丢失时，应保留说明与可用的页面导航。地球回退到静态 Canvas；实验室提供降级说明及重试入口。Three.js 的构建分包可能触发体积警告，需结合实际加载与运行效果评估，不能将警告直接视为构建失败。

## 样式与静态资源

- [index.css](../src/index.css)：基础布局与公共样式。
- [themes.css](../src/themes.css)：亮暗主题与语义颜色。
- [refinement.css](../src/refinement.css)：页面细节、卡片、项目展示与交互样式。
- [atmosphere.css](../src/atmosphere.css)：地形纹理、柔光与背景网格。
- 场景样式位于 `src/components/scenes/scenes.css` 和 `scenario.css`；修改时同时验证嵌入、展开及手机横竖屏布局。

样式加载顺序见 [main.tsx](../src/main.tsx)。新增颜色优先复用主题变量，保留键盘焦点提示，并兼容 `prefers-reduced-motion`。项目详情使用原生 `dialog`，维护 Escape 关闭、焦点返回与进入场景后的定位行为。

静态资源维护约定：

- `public/` 文件会复制到 `dist/`；不要放入内部资料、私有设计会话导出物或无关文件。
- 在 React / TypeScript 中使用 `import.meta.env.BASE_URL` 拼接公开资源路径。HTML 的 favicon 和主题脚本由 Vite 处理路径前缀，不重复添加 base。
- `public/data/land-110m.geojson` 为地球陆地数据，保留其 [来源与使用条件](../public/data/README.md)。
- `public/previews/earthwork.webp` 和 `uav.webp` 为本项目合成场景截图，替换时保持图片与项目说明一致。
- `public/atmosphere/terrain.svg` 是装饰性等高线，不代表实际地形。
- 品牌资源位于 `public/brand-logo-3d*.png`，favicon 为 `public/favicon-3d.png`。

## 测试与变更验证

[Playwright 配置](../playwright.config.ts) 先执行生产构建，再在 5178 端口启动预览。该端口须可用，测试不会复用已存在的服务。测试脚本与 CI 浏览器安装步骤分别见 [package.json](../package.json) 和 [构建部署工作流](../.github/workflows/deploy-pages.yml)。

测试覆盖双语、主题与存储降级、响应式布局、资源子路径、项目贡献文案、弹窗和邮箱交互、地球生命周期、手机三维操作、跨场景状态、图形上下文恢复，以及土石方和水源连通计算。计算结果应通过测试数据校验，不能只以动画看起来正常作为依据。

修改后的基本检查为 `pnpm typecheck`、`pnpm lint`、`pnpm format:check`、`pnpm build`；影响页面行为、文案、资源路径或场景计算时运行 `pnpm test:e2e`。至少检查中文与英文、亮暗主题、手机横竖屏，以及键盘和减少动态效果模式。

文本统一使用 UTF-8、LF 和两个空格缩进；约定见 `.gitattributes`、`.editorconfig` 与 Prettier 配置。失败截图和跟踪文件位于忽略提交的 `tmp/test-results/`，不要将测试产物作为站点资源发布。

## 部署维护

工作流为 [deploy-pages.yml](../.github/workflows/deploy-pages.yml)。仓库已公开，发布分支为 `main`，使用 GitHub Actions 构建并部署 `dist/`。已存在工作流不等于某次更新已经上线，需确认相应提交的部署任务成功。

首次启用：

1. 确认仓库满足 [GitHub Pages 套餐条件](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。私有仓库需要支持私有仓库 Pages 的套餐；不要为消除报错而自行更改仓库可见性。
2. 在仓库 Settings → Pages → Build and deployment 中将 Source 设为 GitHub Actions。
3. 在 `main` 上运行工作流，等待构建和部署任务都成功，再验证站点和静态资源访问。

工作流使用固定版本的 Node.js 和 pnpm、锁文件安装依赖，并执行代码检查、生产构建和浏览器回归。只有 `main` 的非 PR 运行上传 `dist/`；部署任务依赖构建成功。仅部署任务获得 `pages: write` 与 `id-token: write`，使用内置 `GITHUB_TOKEN`，不要求额外个人令牌。Actions 均固定到具体提交，更新时应核对对应版本与输入参数。

部署失败时先查看 Actions 的失败步骤：

- 检查或测试失败：先本地复现，不跳过检查直接发布。
- Pages 配置失败：核对套餐、Source 和仓库权限；工作流不会自动替账户升级套餐或首次开通 Pages。
- 站点或资源 404：确认部署确已成功，访问地址包含 `/zzq-techfolio/`，并排查是否重复或遗漏 base 前缀。

迁移仓库名、子路径或域名时，同步调整 [vite.config.ts](../vite.config.ts) 的 `base`、[index.html](../index.html) 的 canonical / Open Graph URL、测试配置和测试中的显式资源路径，并更新文档中的地址。当前使用 hash 锚点导航，无需服务端路由重写。
