# 地理数据来源

`land-110m.geojson` 使用 Natural Earth 1:110m Land 数据，用于首页球面地理可视化。

- 数据来源：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- 原始文件：https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson
- Natural Earth 数据为 public domain：https://www.naturalearthdata.com/about/terms-of-use/

数据保存在本地，运行时不请求外部地图服务。
